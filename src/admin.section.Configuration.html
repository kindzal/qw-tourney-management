Automatic Game Reminders

⚠️ Important ⚠️

These reminders will not work without Discord Role IDs being set up for all teams in the Teams tab.

Enables automatic game reminders on the day of scheduled matches and chasers to prompt players to schedule their games.

Chasers are sent from mid-week (Wednesday) until the deadline for the current round or until the game has been scheduled.

✗ Status: Disabled
✓ Status: Enabled

Automatic Game Imports

Enables automatic game importing from the QuakeWorld Hub.

The auto import runs between 19:00 and 23:59 every 30 minutes and imports games that match the following criteria:

  • have a Match Tag configured for the tournament
  • their Match Tag does not contain keywords configured in Match Tag exclusions
  • are dated between tournament start and end date
  • are present in the tournament Schedule
✗ Status: Disabled
✓ Status: Enabled

Automatic "Fix Me" Notifications

⚠️ Important ⚠️

These notifications will not work without the "Discord admin channel webhook" being set up in the Configuration tab.

Enables automatic notifications sent to the Discord #admin channel about issues found relating to imported games.

✓ Status: Enabled
