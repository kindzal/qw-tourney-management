Read the below first to understand what you are about to do!

Check FIX-ME tab for any issues as a result of game import.

When using the automated games import feature and/or Reports Watcher Discord Bot, there is no need to import games by hand. Note that the ⚠️ Important section still applies regardless.

Manual Import Instructions

If for any reason games need to be imported manually, follow these steps:

  1. Insert Hub URLs into cells A1:A30 (1 match at a time, any number of maps). Format as follows: https://hub.quakeworld.nu/games/?gameId=113867
  2. Click Run Game Import. Successful imports move the URL to the ImportedURLs tab. Game which had already been imported is skipped. Proceed to step 3 once complete.
  3. Click Run Update Stats to recalculate system stats and to refresh the Web App data.
