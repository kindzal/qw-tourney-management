On this tab you can configure the layout of the weekly schedule message posted to Discord.

Select the Round for which you want to post the schedule to Discord using the dropdown above.

You can use Preview post to validate the info before posting.

Once happy click Post weekly schedule to Discord button to post the schedule to Discord.

⚠️ Important ⚠️

Below is for QML use predominantly to help with arranging games. Before posting the poll:

  • make sure Discord Role ID is set for each Team
  • rejig Players in Team Roles on Discord before each round
