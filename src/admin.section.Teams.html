This tab is used to record teams taking part in the tournament.

The columns you need edit / enter are Team Tag, Team Name, Players and Team Tag Display.

These columns are also highlighted in yellow.

Discord Role ID and Discord Channel Webhook are optional.

They are used for automatic game reminders posting to Discord and for manual availability polls.

⚠️ Important ⚠️

If a team tag starts with an apostrophe (') you need to add an extra apostrophe (') to the beginning of the tag in Team Tag Display due to a slight quirk with Google Sheets.

Team Tag and Team Tag Display are used to link team names and team tags throughout this system so need to be set up correctly.

Tags should be provided upfront and used consistently by teams in their games.

⚠️ Important ⚠️

For teams who use multiple tags the system supports a special tag separator (‡).

To use this functionality enter Team Tag and Team Tag Displayas follows:

tag1‡tag2‡tag3
