This tab is used to record teams taking part in the tournament.

The columns you need edit / enter are Team Tag, Team Name and Players>.

These columns are also highlighted in yellow.

Discord Role ID and Discord Channel Webhook are optional.

They are used for automatic game reminders posting to Discord and for manual availability polls.

⚠️ Important ⚠️

If a team tag starts with an apostrophe (') you need to escape it with a backslash (\) in Team Tag due to a slight quirk with Google Sheets.

It should be \'tro for a team with a tag of 'tro as an example.

Team Tag is used to link team names and team tags throughout this system so needs to be set up correctly.

Tags should be provided upfront and used in games consistently.

⚠️ Important ⚠️

For teams who use multiple tags the system supports a special tag separator (‡).

To use this functionality enter Team Tagas follows:

tag1‡tag2‡tag3
