Use this tab to record a WO (or any game that didn't happen / it's not on the Hub) but you want it recorded.

# The next consecutive number.

Stage 'Group' or 'Playoff'.

Round Round number or 'Quarterfinals', 'Semifinals', 'Final', etc. This value needs to be one of the configured Round on the Schedule tab.

TeamA Name of the winning team. This needs to be a Team Name from the Teams tab.

MapsWonA How many map wins to award the winning team.

Score Example: 3-0

TeamB Name of the losing team. This needs to be a Team Name from the Teams tab.

MapsWonB How many map wins to award the losing team.

AllMapsJSON Leave blank (as no maps played/recorded).

Date Game date in DD/MM/YYYY.
